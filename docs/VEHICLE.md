# BORA S3 · 운전 차량

유일한 `Ro.rbxlx`의 기존 `Workspace.BoraVehicles.BoraSedan_S1`에 승인된 S3 모델을 적용합니다. 기존 참조를 보존하기 위해 내부 인스턴스 이름은 유지합니다. 기존 차량의 주차 위치와 도로·나무·지도·카메라는 이동하지 않습니다. 반복 빌드는 차량을 복제하거나 사용자가 옮긴 위치·부품을 초기화하지 않습니다.

## 조작

- 운전석 앞문 근처 **E**: 문 열기 → 몸 숙여 탑승 → 문 닫기.
- **W/S** 가속·감속 후 후진, **A/D** 조향, **Space** 브레이크.
- **V** 3인칭 / 1인칭. 1인칭은 마우스로 둘러봅니다.
- 운전 중 **E**: 정차 후 하차. 주행 중 요청하면 먼저 제동합니다.
- 나머지 세 문은 정차 중 **E**로 열기/닫기. 탑승 좌석은 현재 운전석 하나입니다.

터치 조작 버튼, HUD·계기판의 km/h 표시를 제공합니다. 창 포커스를 잃으면 누르고 있던 입력을 해제하고, 입력 통신이 끊기면 제동합니다.

## 외형·유리·실내

현재 편집 원본은 `assets/vehicles/BoraS3/BoraS3.blend`입니다. 사용자가 제공한 자동차의 패널 접합과 실내 구성을 참고해 새로 제작했으며 예시의 메시·UV·텍스처를 복사하지 않았습니다. 사용자가 거부한 `BoraS2_FitFix`도 사용하지 않았습니다. 운전자를 향하도록 핸들을 교정한 상태를 2026-10-18 사용자가 승인했습니다. 승인본의 176,384 triangles를 보존하고 재질·동작 그룹별로 합쳐 84개 렌더 부품으로 내보냈습니다. 각 native 메시에는 최대 7,600 triangles가 들어갑니다.

창문은 별도의 투명 **Glass 재질 메시**이며 실내 그림이 붙은 텍스처를 사용하지 않습니다. 좌석·대시보드·화면·콘솔·문 안쪽·핸들은 실제 입체 형상입니다. 문 유리와 내장재는 경첩을 따라 함께 움직입니다. Eye Attachment를 운전석 시야 기준으로 사용하며, 1인칭에서는 머리와 액세서리만 로컬에서 숨깁니다.

가상 브랜드 BORA를 사용합니다. 계기판·내비게이션·번호판 PNG는 S3 제작 그래픽입니다. 이전 Tripo 원본과 S1/S2 파일은 제작 기록으로 남으며 현재 렌더 메시로 사용하지 않습니다.

## 구조와 검사

`VehicleFactory`는 Chassis에 시각 부품을 연결하고 문·바퀴·핸들에 Motor6D 축을 만듭니다. `VehiclePhysics`와 `VehicleDynamics`는 지면을 따라가는 아케이드 이동·조향·가감속을 계산합니다. 전진 상한 약 108km/h, 후진 약 25km/h입니다. 서버가 이동과 운전자 권한을 관리합니다. 차체는 주행 중에도 Anchored 상태로 유지하고, 자유 물리 회전과 바퀴별 스프링 힘을 사용하지 않습니다.

2026-10-18 접지력·구동 배분·고속 조향각 제한 실험은 사용자가 회전과 가감속 반응이 더 나쁘다고 평가하여 철회했습니다. 이후 사용자 요청으로 아래의 지면 추종 방식으로 전환했으며, 승인된 핸들 회전 방향 수정은 유지합니다. 거부된 실험은 `archive/vehicle-handling-rejected-20261018`에 기록으로만 보존합니다. 자동 물리 검사 통과를 조작감 승인으로 간주하지 않습니다.

2026-10-18 지면 추종 전환: 바퀴 4개는 ClosedC0의 고정 위치를 유지하고 실제 이동 거리만큼 회전합니다. 차량 중심과 주변의 지면 높이로 차체 전체의 높이·경사를 맞추며, 바퀴별 접촉 힘으로 가속하지 않습니다. 수직 스프링·임펄스·물리 관성으로 생기는 출렁임은 제거했습니다. 차량 중심에 진행 가능한 지면이 있으면 이동하며, 지면이 사라지거나 높이·경사가 허용 범위를 넘으면 정지합니다. 차체 크기의 Blockcast로 벽·기둥을 검사하고 장애물 앞에서 멈춥니다. 하차 대기는 엔진 AssemblyLinearVelocity가 아닌 컨트롤러의 실제 주행 속도로 판단합니다.

키 입력 변화는 최대 60Hz로 다음 렌더 프레임에 전송하며 유지 중에는 약 20Hz로 갱신합니다. 이 입력 전달 개선만 유지합니다. 서버가 계산하는 이동과 0.4초 입력 단절 시 제동은 유지합니다.

탑승·하차는 업로드 애니메이션 없이 문 회전과 캐릭터 이동/관절 자세를 함께 조절합니다. 탑승 전에 아바타의 눈 높이를 재서 앉은 몸의 높이를 운전석 시야에 맞춥니다. 기본 앉기 동작에 R15 팔 IK를 연결하며 R6는 단순 팔 자세를 사용합니다. 커스텀 아바타 체형은 Play에서 추가 조정이 필요할 수 있습니다.

- `tests/vehicle.luau`: 분리 축·참조 저장/복구·유리·입력 검증·가감속/후진·조향·고정 바퀴 위치·아케이드 이동.
- `tests/vehicle_lifecycle.luau`: 실제 서버 함수의 탑승/좌석/문/운전/하차, 타인 조작 차단과 캐릭터 상태 복구.
- `tests/vehicle_arcade.luau`: 평면·20% 경사의 네 바퀴 높이, 스프링 힘 미사용, 포장 이음새 높이 변화, 벽·지면 끝 정지, 정차 시 위치 유지, 후진 및 30/60/120Hz 비교.
- `tests/vehicle_input.luau`: 실제 클라이언트 콜백의 누름·해제·브레이크·포커스 상실·입력 취소·유지 패킷. 통신 지연을 제외한 입력 대기 검사.
- `tests/vehicle_assets.py`: S3 승인본 해시·삼각형·좌표 변환·메시/UV/법선·텍스처·투명 유리·핸들 방향·운전석 시야.
- `tests/vehicle_project.py`: 기존 맵 보존·차량 한 대 설치·반복 빌드와 사용자 편집 보존.
- `tests/vehicle_installation.py`: 저장된 Place의 실행 코드·참조와 설치된 에셋 전체의 해시 일치.

위 검사는 자동 모델/코드 검사입니다. Studio를 자동 실행하지 않았으므로 실제 엔진의 운전 감각과 아바타 동작은 Play로 확인해야 합니다. 자동 주행·신호에 따른 강제 정지는 포함하지 않습니다.

## 제작과 설치

빌드 진입점은 `tools/build_tree_v4.luau`입니다. 같은 Ro.rbxlx에 차량과 서버/클라이언트/RemoteEvent를 추가하며 기존 맵을 보존합니다. `tools/install_tree_v2.ps1`이 native mesh와 PNG를 Studio `content/BoraVehicleKit`에 설치합니다. 이 로컬 경로는 이 PC의 Studio 제작용이며, 다른 PC·온라인 배포에는 Roblox 업로드와 경로 교체가 필요합니다.

S3 제작은 `build_bora_s3.py`, 핸들 방향 교정은 `orient_s3_steering.py`, 프로젝트 내보내기는 `export_s3_project_assets.py`를 Blender 백그라운드에서 실행합니다. 내보내기는 승인된 `.blend`를 저장하지 않고 읽습니다. Blender 좌표를 Roblox `(-X, Z, Y)`로 회전하고 1 stud = 0.28m로 변환합니다. 문·바퀴·핸들 피벗과 운전석·시야·서스펜션 위치는 `assets/vehicles/local/manifest.json`에서 관리합니다. Attachment는 실제 XML 저장 속성인 CFrame을 사용합니다.

한글 문자열은 UTF-8 CDATA로 저장합니다. `tests/roblox_text_xml.py`와 `tests/vehicle_text.luau`에서 실제 한글 문구와 소스의 왕복 보존을 확인합니다. 모델 교체는 기존 차체의 물리 부품·위치를 유지하며 새 모델 치수에 필요한 피벗·좌석·시야·서스펜션 연결을 옮깁니다. 사용자 위치 오프셋과 기존 인스턴스 참조를 보존하며 같은 개정판을 다시 빌드하면 사용자 편집을 유지합니다. `dist/model-application-validation.json`은 맵 배치·도로 설정·신호등 기둥·차량 위치 보존과 최신 모델 적용 검사 결과입니다.

차체 충돌 검사의 API 근거: [Roblox WorldRoot.Blockcast](https://create.roblox.com/docs/reference/engine/classes/WorldRoot#Blockcast). 이 검사는 시작부터 겹친 물체를 검출하지 않으므로 정상적인 빈 주차 위치에서 시작하는 것이 전제입니다.
