# 생물 수집 프로토타입

## 체험 안내

중앙에서 바다로 가서 첫 생물을 찾고 장착합니다. 속도·힘 기구에 올라 훈련하고, 포획 코인으로 개인 훈련 장비를 강화해 보세요. 속도·힘 각각100이면 첫 환생이 가능합니다. 속도 최고 기록50은 산호 구역,150은 먼바다를 엽니다. 해금 기록은 환생 후에도 유지됩니다.

먼바다 일반 포획으로 흔적20개를 모은 뒤 암초 고리에서 해신룡을 깨웁니다. 보관함에서 장착하고 중앙 전시대에 도전할 수 있습니다. 자신의 대표가 있다면 다른 보유 개체로 대표 교체전을 진행합니다.

- PC: 채집/깨우기는 E 또는 화면 버튼을 약1초 누릅니다. 기구 위에 서면 훈련하고 내려오면 멈춥니다.
- 모바일: 화면의 찾기/깨우기 버튼을 길게 누릅니다. 이동 조작으로 기구에 올라갑니다.
- 내 생물: 개체 선택·장착. 환생: 조건 확인 후 실행. 기구 근처의 장비 강화: 비용 확인 후 구매. 전시대 근처: 도전 버튼.
- 장비0~3 배율은1/1.25/1.5/1.75, 구매 비용은3/6/12코인입니다. 속도·힘 훈련에 함께 적용됩니다.
- 코인·장비·수집 개체·선택·훈련·환생·구간 최고 기록·흔적·진행 기록은 **같은 서버 접속 세션에서만 유지**됩니다. 환생은 현재 속도·힘만0으로 돌립니다. DataStore/계정 영구 저장은 없습니다.
- 임시 표현 자산은 정식 아트 품질 승인을 받은 결과로 간주하지 않습니다.

## 개발용 보존 정보

- 정확한 소스: `src/creature_prototype/` 아래20개 UTF-8 `.luau` 파일(총105,823바이트).
- 원래 인스턴스 경로·클래스·서비스·모듈 참조·주요 장면 루트·스폰/CFrame·핵심 설정: `assets/creature-prototype/manifest.json`.
- 파일별 SHA-256, 원문 재읽기 대조 및 Place 불변 검사: `assets/creature-prototype/validation.json`.
- 주요 실행 배치: 서버 로직은 ServerScriptService, 공통 규칙은 ReplicatedStorage, 클라이언트는 StarterPlayer.StarterPlayerScripts입니다. 전투 규칙 ModuleScript는 전시 서버 Script의 자식입니다. ServerStorage의 생물 Tool 및 ReplicatedStorage의 미리보기·RemoteEvent도 필요합니다.
- 원래 중앙 스폰은 Workspace.SpawnLocation이며 현재 편집 위치는(0,0.9,-34)입니다. 정확한 회전·크기는 manifest의 유형 보존 숫자 배열을 참조하세요.
- 이 보존본은 **소스와 선택한 구성 정보**입니다. 모델/.rbxmx·전체 장면·각 파트·외부 메시/텍스처·Terrain·모든 속성/태그/참조는 보존하지 않았습니다. 대용량 과거 편집 Attributes 누락도 manifest에 적었습니다.
- 종별 템플릿의 경로·클래스·개수와 외부 에셋 ID는 목록만 보존했습니다. 모델 형상이나 외부 에셋 본체는 포함하지 않습니다. 소스만으로 전체 장면을 완전히 복원할 수 있다는 보장은 없습니다.
- 자동 설치/복원 도구는 만들지 않았습니다. 원래 서비스를 준비하고 manifest에 따라 Script/LocalScript/ModuleScript를 대응해야 하며, **재설치·복원 실행 검증은 미실시**입니다.
- 유일한 Place는 기존 `Ro.rbxlx`입니다. 이 작업에서 덮어쓰거나 새 Place를 저장하지 않았고, `tools/build_tree_v4.luau`를 변경·실행하지 않았습니다. Studio의 현재 Place1 메모리를 원본으로 읽었습니다.
