# Ro · 단일 Roblox 프로젝트

**작업 파일은 최상위 `Ro.rbxlx` 하나입니다.** 앞으로 이 파일에만 적용합니다. 예전 비교·테스트·빈 작업 맵과 Place 백업 파일은 삭제했습니다. 새 프로젝트나 별도 테스트 맵을 추가하지 않습니다.

현재 파일에는 표면 굴곡을 줄인 최신 은행나무(v0.4.2)가 적용되어 있습니다. 목재만 있는 나무와 잎이 있는 나무를 함께 확인할 수 있습니다.

첫 동네 구역은 기존 십자 교차로 `XJunction_5` 주변의 `Workspace.BoraNeighborhood_01`입니다. 카페·약국·마트·주택과 가로등·벤치·점자블록을 배치합니다. [구역 위치와 제작·검사 범위](docs/NEIGHBORHOOD.md)를 참고하세요.

**플러그인 → 보라동 건물 → 건물 편집**에서 기존 건물을 선택해 종류·1~24층·크기·색상·간판 이름을 바꿉니다. **건물 설치**로 새 건물을 지면에 놓습니다. 본체는 층별로 조립하고 Tripo 벽등은 Blender에서 정리한 공유 메시를 사용합니다. [건물 편집과 적용 범위](docs/BUILDINGS.md)를 참고하세요.

**층별 도면**에서 벽 선·벽 블록·계단·전 층 엘리베이터를 배치하고, **문 넣기**로 벽에 통과할 수 있는 문을 만듭니다. 기존 보라빌라 101에는 정면 출입구와 1~3층을 연결하는 계단·엘리베이터·복도가 있습니다. Play에서 E로 승강기를 호출하고 객실 패널에서 이동할 층을 선택합니다.

## 지도 · 도로 편집

**플러그인 → 지도 · 도로**를 엽니다. **지도 위에서 보기 → 기준 거리 입력 → 축척 맞추기(두 점 클릭) → 도로 그리기** 순서입니다. 지면을 클릭해 점을 추가하고 Enter로 확정합니다. 기존 도로는 선택 후 점 편집에서 드래그로 수정합니다. 도로 폭·차선·인도·곡선도 슬라이더로 바꿀 수 있습니다. 지도는 Play에서 숨겨지고 생성한 도로는 남습니다.

첨부 지도는 참고 이미지로 넣었으며 실제 축척은 사용자가 기준 거리로 맞춰야 합니다. 새 도로 시작·끝점을 기존 도로 중간에 붙이면 **T자 교차로**, 도로를 가로질러 그리거나 T자 반대편에 붙이면 **십자 교차로**를 만들고 인도·차선을 정리합니다. 연결점 드래그와 폭 변경에도 연결부가 갱신됩니다. 사용법·현재 한계는 `docs/ROAD_EDITOR.md`를 참고하세요. 자동 이미지 인식은 이후 범위입니다.

도로 탭의 **교차로 시설**에서 횡단보도·정지선·Tripo 신호등을 켜고 끄며 간격·깊이·직진/좌회전 시간을 드래그합니다. 기존 교차로에는 **교차로 다시 계산**으로 적용합니다. Play에서 진입로별 직진 → 좌회전을 순환하며 지정하지 않은 방향은 건너뜁니다. 각 단계 사이 황색 3초·전체 적색 1.5초를 둡니다. 인접 교차로 사이 공간이 부족한 방향은 노면 표시를 생략하고 패널에 알립니다.

**보행 신호**를 켜면 횡단보도 양쪽에 Tripo 보행 신호등을 배치합니다. Play에서 모든 차량 단계가 끝난 뒤 차량 전체 빨강 상태로 보행 초록·점멸·종료 대기 시간을 진행합니다. 이 구간에는 우회전 진행 허용값도 꺼집니다. 보행 시간·점멸 시간도 슬라이더로 조절합니다. 횡단보도가 생략된 방향에는 보행 신호등을 만들지 않습니다.

**차로 방향** 탭에서 도로의 진입 방향을 고른 뒤 차로별 직진·좌회전·우회전을 조합합니다. 정지선 뒤에 화살표가 생기며 폭·점 편집 후에도 설정을 유지합니다. 복수 선택할 수 있고, 출구 도로가 없는 방향은 선택할 수 없습니다. 좌회전이 있는 진입로에는 4구 신호등과 좌회전 단계가 자동으로 추가됩니다. 우회전 전용 신호는 없으며 정지·양보 정책을 기록합니다. 실제 차량의 주행·정지 제어는 이후 단계입니다.

## 차량 · BORA S3

Play에서 세단의 운전석에 다가가 **E**로 탑승합니다. **W/S** 전진·후진, **A/D** 조향, **Space** 브레이크, **V** 1·3인칭 전환, **E** 정차 후 하차입니다. 승인된 BORA S3 외형과 실내를 적용했으며 문·바퀴·핸들이 분리되어 움직입니다. 기존 차량 위치를 보존합니다. [차량 제작·검사 범위](docs/VEHICLE.md)를 참고하세요.

차량 신호등과 보행자 신호등에는 정리한 최신 메시·텍스처를 적용했습니다. 기존 기둥과 배치는 유지하며 점등 위치를 새 메시의 렌즈에 맞춥니다.

## 나무 편집

1. `Ro.rbxlx`를 Roblox Studio에서 엽니다.
2. 나무 한 그루를 클릭합니다. 패널이 닫혀 있으면 **플러그인 → 보라동 나무 → 나무 편집**을 누릅니다.
3. 성장·큰 가지 수·퍼짐·굵기·잎 밀도·시드를 드래그합니다. 구조 설정은 놓을 때 적용됩니다.
4. 숫자 직접 입력 후에는 **가지 설정 적용**을 누릅니다. 시드 슬라이더는 0~999이며 직접 입력은 0~2147483646까지 가능합니다.
5. Ctrl+Z/Ctrl+Y로 되돌리기·다시 실행을 할 수 있습니다.

## 제작 도구 갱신

Studio 편집을 저장하고 닫은 뒤 아래 도구를 실행합니다. 빌드는 플러그인과 `Ro.rbxlx` 안의 도구·런타임 소스를 갱신하고 기존 신호등의 점등 부품을 업그레이드합니다. 도로·나무·지도 배치와 저장된 차로 방향은 보존합니다. 새 Place는 생성하지 않습니다. 갱신 후 같은 `Ro.rbxlx`를 다시 엽니다.

가상 데스크톱 전환을 방지하기 위해 자동으로 Studio를 실행하거나 활성화하지 않습니다. 기본 검사는 파일과 자동 테스트로 진행합니다.

Studio 업데이트 직후 차량·나무·지도·신호등이 안 보이면, 버전별 로컬 에셋 폴더가 비어 있는지 확인합니다. `powershell -ExecutionPolicy Bypass -File tools/install_tree_v2.ps1 -AssetsOnly`로 해당 에셋만 복구하고 Studio를 다시 엽니다. 이 옵션은 맵과 플러그인 코드를 저장하지 않습니다.

```powershell
lune run tools/build_tree_v4.luau
powershell -ExecutionPolicy Bypass -File tools/install_tree_v2.ps1
```

`src`는 편집기·나무 생성기 소스, `assets`는 메시·텍스처, `dist`는 플러그인과 이미지·JSON 검증 결과입니다. `.rbxmx` 파일은 프로젝트가 아닌 플러그인/모델 에셋입니다.

형상 검사: `tests/parametric_geometry.luau`, `tests/parametric_factory.luau`, `tests/tree_surface.luau`. 프로젝트·소스 갱신 검사: `tests/project_update.py`.

가지 표면·저장 방식은 `docs/PARAMETRIC_TREES.md`를 참고하세요. 현재는 로컬 Studio 제작 버전이며 온라인 배포 전에는 로컬 에셋 경로 전환과 성능 검토가 필요합니다.
